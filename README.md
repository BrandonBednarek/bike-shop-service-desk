# Bike Shop Service Desk

[![CI](https://github.com/BrandonBednarek/bike-shop-service-desk/actions/workflows/ci.yml/badge.svg)](https://github.com/BrandonBednarek/bike-shop-service-desk/actions/workflows/ci.yml)

An internal web app for the repair side of a small bike shop. It tracks each repair from check-in to pickup, and gives the owner a dashboard of late jobs, bikes waiting to be picked up and time overruns.

**Status:** in development. How to run it and the demo accounts will be added here.

My reasoning for what I built, and what I left out, is in [docs/DECISIONS.md](docs/DECISIONS.md).
